Chiavi API

Le chiavi servono agli script e agli altri servizi (app Nextcloud, Plico, curl, Comandi rapidi di iPhone) per usare l'API. Ognuna ha i suoi permessi e si può revocare in ogni momento. La pagina web non ne ha bisogno.

Area admin disattivata

Per attivarla imposta la variabile CONVERTER_ADMIN_PASSWORD, oppure scrivi la password nel file admin-password della cartella dei dati (DATA_DIR, predefinita /work/data), poi riavvia il servizio.

# Security policy

Please **do not** open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/EmaLau/universal-converter/security/advisories/new) instead.

Only the latest release is supported. Remember that the web page has no login: keep the service on a trusted
network or behind a reverse proxy with authentication (see *Security and privacy* in the
[documentation](server/docs/documentation.md#security-and-privacy)).
